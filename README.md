📔 Personal Journal Manager
🐍 Python Project 6
A simple command-line journal manager that lets users add, view, search, and delete journal entries.
✨ Features
⦁	➕ Add a new journal entry with the current date and time.
⦁	📖 View all saved journal entries.
⦁	🔎 Search entries using a keyword or date.
⦁	🗑️ Delete all entries after confirmation.
⦁	🚪 Exit the program safely.
⦁	💾 Entries are stored in a text file named `journal.txt`.
🛠️ Technologies Used
🐍 Python
📄 File Handling
📅 datetime module
💻 Command Line Interface
📂 Project File
`PROJECT 6.PY`
▶️ How to Run
1. Open the PROJECT 6.PY file in Python IDLE, VS Code, or another Python editor.
2. Run the program.
3. Choose an option from the menu by entering 1, 2, 3, 4, or 5.
4. Journal entries are automatically saved in journal.txt.
📋 Menu Options
Option	Action
1	➕ Add a New Entry
2	📖 View All Entries
3	🔎 Search for an Entry
4	🗑️ Delete All Entries
5	🚪 Exit

🧠 Main Python Concepts

👨‍💻 Project Summary
Personal Journal Manager is a beginner-friendly Python project for practicing functions, loops, conditions, file handling, searching, and date-time formatting. It stores journal entries with timestamps and provides a simple interactive menu.
